# System 0 Overview

System 0 is the low-power background substrate for the sandbox. It maintains salience, geometric memory, prospective traces, energy budgets, and goal utility before escalating to higher-cost reasoning.

Core loop:

1. Sense context
2. Retrieve from geometric memory
3. Update salience
4. Modulate salience through ternary field dynamics
5. Build goal utility frontier
6. Escalate to System 2 planner only when utility exceeds threshold
7. Learn from prospective forecast vs observed outcome
